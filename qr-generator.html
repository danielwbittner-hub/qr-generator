        Begriffe kurz erklärt
        
Modul: eines der kleinen Quadrate, aus denen der Code besteht.

        Ruhezone: freier Rand um den Code. Scanner brauchen ihn, um den Code von der Umgebung zu trennen – Norm sind 4 Module.

        Positionsmarker (Finder Patterns): die drei großen Quadrate in den Ecken, an denen der Scanner Lage und Größe erkennt.

        Version: Rastergröße des Codes (Version 1 = 21 × 21 Module, jede Stufe +4). Längere URLs brauchen höhere Versionen – ein Kurzlink mit serverseitiger Weiterleitung hält den Code klein.

        Fehlerreserve: Die Fehlerkorrektur arbeitet blockweise. Das Tool rechnet aus, wie viel davon Logo und Gestaltung schon verbrauchen – der Rest fängt Kratzer, Knicke und Druckfehler ab.

        Druckgröße: Entscheidend ist die Modulgröße. Empfehlung: Modul mindestens Scanabstand ÷ 230 und nie unter 0,4 mm (Faustregel: Code ≈ Abstand ÷ 10).

        Kontakt (vCard): Visitenkarte im Code. Das Handy bietet nach dem Scannen „Kontakt speichern“ an. Jede Angabe macht den Code dichter – für kleine Drucke nur Name, Telefon, E-Mail.

        Serie: Excel (.xlsx), CSV oder .vcf laden, jede Zeile wird ein Code. Das ZIP enthält je Zeile die gewählten Dateien und ein Protokoll.csv mit Version, Modulgröße, Fehlerreserve und Testscan.

        Druck-PDF: Code als Vektor in CMYK mit exaktem Endformat – Schwarz als 100 % K statt Vierfarbschwarz, CI-Farben mit ihren Werten aus dem CD-Manual. Ein farbiges Logo liegt als RGB-Bild darin; für reinen CMYK-Druck „Logo einfarbig“ wählen oder nur die Freifläche freihalten und das Logo im Layout setzen. Der Text unter dem Code ist eine 1200-ppi-Schablone in der Codefarbe.
